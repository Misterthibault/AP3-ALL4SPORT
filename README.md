## Rapport de suivie de projet

-------------------
### Outils et bibliotèque utilisé:

**Git Hub:** Pour centraliser le projet
**VS code:** IDE pour coder en Java  
**Discord:** pour la communication et le partage de fichier/code  
**Trello:** Pour organiser les tâches de chacun  
**Mocodo:** Pour la réalisation du MCD de la base de donnée
**Serveur Local XAMPP:** Pour utiliser une BDD en local

----------------------------------
### Résumé de ce qu’il faut faire:


#### Création d'un site marchand pour une entreprise de sport

Gestion de compte client, de leur commande et de leur historique.
Gestion du stockage des magasins et des entrepots
Chiffrer les données des clients et assurer une sécurité
